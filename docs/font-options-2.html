見微 · 书法字标方向

繁体「見微」+ 流动书法体（行楷 / 行书 / 行草 / 狂草），避方正。

字标固定用书法艺术字，正文与标题仍走宋/楷/黑/码 选择器（正文可维持简体或全站转繁，待你定）。四款按「连绵 / 写意」递增：马善政毛笔行楷（温润学者气）→ 龙藏行书（流畅连绵）→ 志莽行草（飞动）→ 刘建毛草（狂草，近难辨，纯字标用）。罗马名配 Cormorant Garamond。
