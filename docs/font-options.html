见微 · 艺术字方向

为「见微」二字选一款艺术字。下方各用对应字体渲染品牌字 + 标语 + 罗马名。

方向分两脉：装饰宋体（站酷小薇——优雅、文学、可读）；书法体（马善政毛笔行楷 / 龙藏行书 / 志莽行草 / 刘建毛草——手作、学者气）。字标固定用艺术字，正文与标题仍走宋/楷/黑/码 选择器。罗马名 Jianwei 可配优雅衬线（Cormorant）或雕刻体（Cinzel）。
